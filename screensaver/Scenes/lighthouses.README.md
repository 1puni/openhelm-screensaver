# OpenHelm Lighthouses

A quiet, offline Mac screen saver: a dark nautical chart with a lighthouse sweeping its real
sectors, stopping at the first land it meets. Two charts, chosen under **Options…**:

- **Tynningö — Stockholm archipelago** · Fl(2) WRG 6s over Oxdjupet (the default)
- **Alcatraz — San Francisco Bay** · Fl W 5s

macOS 14 Sonoma or newer, Apple Silicon or Intel.

Decorative light studies, **not for navigation**. Both charts are original, simplified
portrayals built only from open data; see *Credits* below.

## Install

1. Unzip, then double-click **OpenHelm Lighthouses.saver**. macOS offers to install it for
   you; choose **Install for this user only**.
2. This build is not yet notarised by Apple, so macOS may say it can't verify the developer.
   Click **Done**, open **System Settings → Privacy & Security**, scroll down, click
   **Open Anyway** next to *OpenHelm Lighthouses*, then double-click the saver again.
3. Open **System Settings → Screen Saver**, pick **OpenHelm Lighthouses**, and use
   **Options…** to switch charts and read the credits.

Already have the earlier *OpenHelm Alcatraz Preview*? It is included here; remove the old one
(right-click it in the Screen Saver list → Delete) so only one copy loads.

To uninstall, right-click OpenHelm Lighthouses in the Screen Saver list and choose Delete.
